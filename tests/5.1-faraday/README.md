## 物理模型
- 圆柱磁区（R=0.15 m）内 B(t)=B₀·sin(2πf t) 垂直纸面 ⇒ 涡旋感应电场：
  `E_φ = −(r/2)·dB/dt`（区内）/ `−(R²/2r)·dB/dt`（区外）；ℰ = −dΦ/dt（环套住磁区后饱和）
- 载流子角位移 ∝ I = ℰ/R_环阻；E_i 箭头方向随 dB/dt 反号翻转（楞次）
- 单位：T / Hz / m / V/m / mV / mA，动画 1:1 秒

## 踩坑
- 圆心密集区标签：锚在圆上任何相机角都会互撞（vis51 三连）⇒ **标签组 = 原点锚 + 屏幕固定偏移竖排**（E_i/Φ/导体环 三条），特征旁只留最短的 `@{E}_i`
- B 标签要锚到磁区外（0.30）：锚在 R 边上时低仰角撞盘心 ⊙/⊗
