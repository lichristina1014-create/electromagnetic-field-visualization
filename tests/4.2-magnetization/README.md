# 4.2 磁介质的磁化 · 装配源与回归自检

对应页面：`../../4.2-magnetization.htm`（105,164 B，**生成物，不要直接改**）

## 页面在讲什么

用户给的原话需求：

> 磁介质是由无数多的分子电流组成的，没有外加磁场的时候分子电流是杂乱无章排列的，
> 有外加磁场以后，分子电流取向排列，在介质的外表面形成宏观的环形电流，从而产生磁化磁场，
> 空间总场是有外加磁场和磁化磁场共同产生的。

落地成三个页签（`state.mode` = `molecular` / `nofield` / `poling`）：

| 页签 | 讲什么 | 画面 |
|---|---|---|
| ① 分子电流 | 磁介质 = 无数小环流；磁矩 `@{m} = i·S`；环流的磁场按右手定则 | 一个放大的分子环 + 它的场线 + 可拖的 `i`/环半径 |
| ② 无外场 | 分子电流**杂乱无章** ⇒ 相邻环接触点反向抵消 ⇒ 外表面没有宏观环流 ⇒ `M = 0` 不显磁性 | 95 个确定性伪随机取向的分子环（每层六方密排、相切）+ 与 2.3 电介质对照 |
| ③ 加外场 | 分子电流**取向排列** ⇒ 内部抵消、外表面合成一圈宏观环形电流 `@{K}_b = M×n̂ = M` ⇒ 磁化磁场 `@{B}′ = µ₀M` ⇒ 总场 `@{B} = @{B}₀ + @{B}′` | 取向排列过程动画（可拖进度条 t）+ 侧面束缚电流 + 三条闭合的 `@{B}′` 橙环 + 总场青线 + 灰参考线 |

### 定量链条（`chk42.js` ① 对整条链做 30 组恒等式断言）

```
m   = i·πr²          分子磁矩（10⁻²⁴ A·m²，≈ 玻尔磁子量级）
M   = n·m·s          磁化强度（n = 10²⁸/m³，s = 取向度）
K_b = M              圆柱侧面束缚电流面密度（n̂ = ρ̂ ⇒ φ̂ 向）
B′  = µ₀·M           磁化磁场（侧面电流即一个螺线管 ⇒ 内部沿 +z）
B   = B₀ + B′        总场（µ_r = B/B₀）
```

单位制刻意选成**默认参数下三个量同量级**：M ≈ 21 kA/m、B′ ≈ 27 mT、B₀ ≈ 18 mT ⇒ 叠加效果一眼看得见。

### ⚠️ A_VIS = 1.8e4：本页最关键的一次设计修正

真实顺磁质的取向度是朗之万函数 `L(a)`，默认参数下 `a = mB/kT ≈ 3.8e-5` ⇒ `L ≈ 1.3e-5`。
第一版 `A_VIS = 18`（s_vis = min(1, 18·a)）⇒ 默认取向度只有 0.07% ⇒ **磁化完全看不见**，µ_r = 1.0005，与"默认 M ≈ 21 kA/m"的设计意图自相矛盾。

改为 `A_VIS = 1.8e4` 后默认 `s_vis ≈ 0.68`。**画面取向度是示意放大（约 2×10⁴ 倍）**，卡片里「真实取向度 L(a)」一行按**未放大的真实值**如实报告（`toExponential(2)`，写成 `toFixed(3)` 会印出 "0.000"）。这是"强磁性材料"的示意参数，铁磁质的磁畴机制不在本页展开。

### λ 恒定（③ 的一个物理细节）

未饱和区 `M ∝ B₀e` ⇒ `λ = µ₀M/B₀e` 与 t、B₀ **无关**（默认 0.539）⇒ 播放全过程时总场线**形状不变**（物理正确），变化的只是灰线/橙线的淡入。B₀ > 73 mT 后取向饱和、µ_r 回落趋 1。

## 磁场内核（`field-check.js`，Node 离线验证，25/25）

有限长圆柱面电流的 `B(ρ,z)` 用**环堆叠**（完全椭圆积分闭式 + AGM），上画面之前先用 Node 与「直接 2D Biot-Savart 数值积分」（真相源）在 4 点 × 2 分量上钉死。三个坑：

1. **AGM 断点门限 1e-16**：a、b 收敛到同一个 double 后 `(a−b)/2` 停在 ~1e-17 不再下降 ⇒ 用 1e-18 会**永不触发**、200 轮空转（第一版 `E()` 里 `p *= 2` 权重炸到 2^199，算出 −4.6e27）。
2. **奇极项镜像采样**：ρ→0 时单环场的奇极项要靠镜像点采样，否则轴上数值发散。
3. **偶尖峰解析剥离**：环所在处场有对数尖峰，插值前先解析剥离。
4. **端线圈对数发散**：端部线圈用建表绕避（`TBL{44×60, rmax=zmax=±1.10}`）。

已知极限（测试只断言干净区，DATA 行如实报最差值）：跳变量 z=0→−0.988、±0.2→−0.968、±0.3（棒端）→−0.721；∇·B 在 z=0/|z|≥0.45 处 ≤0.001，但 (ρ=0.2, z=±0.2) 处有 ~7% 奇对称残差（镜像采样截断，不随 h 收敛）——**对场线追踪无影响**。`B_ρ(ρ,−z) = −B_ρ(ρ,z)`、`B_z` 偶对称 ⇒ 镜像测试必须带符号。

## B′ 场线种子是实测选出来的

`@{B}′` 的场线只有**贴壁种子**（ρ₀ ≥ 0.19）的磁通管能在画面范围内闭合。实测各种子 max|u|（探针跑出表边界 ±1.10 记为 1.0+）：

| 种子 ρ₀ | max\|u\| | 结论 |
|---|---|---|
| 0.19 | 0.98 | 刚好闭合 |
| 0.222 | 0.78 | 闭合 |
| 0.248 | 0.60 | 闭合 |
| 0.05 / 0.115 / 0.18 | — | 从表边界 ±1.10 伸出 ⇒ 不闭合 |

⇒ `bpLines = [0.19, 0.222, 0.248]`。总场种子 `u0 ∈ {±0.10, ±0.24, ±0.40}`。

## 踩坑记录（本页新添）

1. **`drawLoop` 负数取模崩溃**：`(loopPhase*0.4 + hash)%1` 对负坐标为负 ⇒ 数组负下标 ⇒ `undefined` ⇒ vsub 抛错 ⇒ **切到②③ 页签必崩**，且 tick 的 try/catch 把症状伪装成"画面卡住"。修法 `((…)%1+1)%1`。
2. **t 滑块必须 `state.anim=null`**：拖进度条要彻底取消播放，否则 `anim.u` 与 `state.t` 失配。
3. **插图文字分层**：K_b 标签与说明行曾只差 2px（28% 重叠）⇒ 重排为环底 by+138 / K_b by+152 / 说明 by+168 / by+184，面板加高到 192。`vis42.js` 的 INS 矩形 `{14, H-206, 176, 192}` 钉死这套布局。
4. **nav 迁移的两处连坐**（全站）：4.2 项曾被标成 `active:true`（多页两个 active）且漏 `href`（不可点）——生成器要区分"本页 active 无 href"与"他页 ready 带 href"。
5. **插桩三处 text 入口 str 下标不同**：`txt`→2、`text`→1、`textScreen`→2。
