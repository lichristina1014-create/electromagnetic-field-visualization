## ★ 关键设计（改之前先读）

1. **通量量子 q₀ = 0.125 µC**：把每条场线看成一个"通量管"，每根代表固定电荷 ⇒
   净穿出根数 × q₀ **严格等于** Q内，与球面半径、当面选哪儿都无关。
   q₀ 必须能整除滑块步长 0.25，且要小到"球外电荷也能发出足够多的线"。
2. **方向序列必须"前缀嵌套"**：`dirK(k)` 用加性黄金比低差异序列
   （`z = 1−2·frac(k·0.618…)`、`a = 2π·frac(k·0.754…)`，两个无理数取不同的），
   取前 n 条 = `BASE_LAT.slice(0,n)`。
   ⚠️ 用 Fibonacci 那种 `z = 1−(2i+1)/N` 做不到 —— 总数一变整套方向全换：
   拖滑块看到的是线段乱跳，而且"球外有几条线穿进球面"会随 n 随机跳 0/3。
3. **球外电荷的第 0 条线固定指向球心（`AIM_U`）**：低差异序列里"哪几条恰好指向球面"
   是定死的运气 ⇒ 不钉这一条的话，q₃ 从 0 拖到 1.25 穿入恒为 0。
4. **球外电荷要"贴着"球面放**（模长 0.480 / 0.476 vs R 上限 0.38）：放远画面清爽，
   但球面对它张的立体角小到"一条线都穿不进球面"，② 的核心现象就没了。
5. **`fieldLines()` 的搜索从上次命中的旋转开始试（`_lastRot`）**：一举两得 ——
   小步调整第一次就命中（快），且同一旋转下前缀嵌套才真正生效（画面稳）。
   ⚠️ 自检里 `resetFL()` **必须连 `_lastRot` 一起清**，否则结果不可复现。
6. ⚠️ **单位 1000 倍陷阱**：`fieldN` 出的是 **kV/m** ⇒ Σ(E·n̂)ΔS 的自然单位是 **kV·m**，
   而页面统一用 **V·m** 报 Φ ⇒ `fluxSumExact()` 收尾必须 `×1e3`（漏掉就是 99.9% 的误差）。
7. **球面离散通量收敛慢**：近奇点时球面上 |E| 的 max/min 可达 6.7 倍
   ⇒ `FLUX_N_SUM = 8000`（N=1500 差 0.77%、N=8000 差 0.07%）。
   画给人看的 64 点箭头与"给人信"的 8000 点求和是两套数，chip 标签里带 `≈` + 误差。

## 已知坑（都踩过）

- ⚠️ **`BASE_LAT` 的元素是 `pt` 对象、不是数组**：旋转里写成 `v[0]` 会得 `undefined`
  ⇒ 整套 LATTICES 变 NaN ⇒ 追踪起点 NaN ⇒ **一条线都画不出来，却完全不报错**。
- ⚠️ **预设按钮的取值必须落在滑块量程内**：曾经写过 `q₃=q₄=3` 而量程是 `[−2,2]`
  ⇒ `input[type=range]` 自己 clamp 到 2、`state.q` 仍是 3 ⇒ 滑块显示与真实状态不一致，
  **不报任何错**。自检第 ⑩ 组专门盯这个（点遍所有按钮 × 7 个量）。
- ⚠️ **③ 的默认 P 点不要取"正对 q₃"**（θ=78.5°, φ=27°）：那里 E_外 与 E_内 近反向，
  红/紫两支长箭头几乎平行且反向，看起来像"一根穿过 P 的长线"，平行四边形读不出来。
  默认取球顶附近（θ=24°），"正对 q₃"做成对照按钮。
- ⚠️ **`cdpeval.js` 的 URL 要 `cd ../..`**（本目录 → tests → 平台目录）。写 `cd ..`
  时页面 404、cdpeval 只报"就绪探针超时"，**脚本全 0 却不报错**（空转通过）。
- ⚠️ **进 DOM 的串必须过 `richHTML()`**，且 `kchip(k,v)` 的 **k 与 v 都要过**；
  章节行判定要认 `['§','文本']` 与 `['§ 文本']` **两种**写法。
- ⚠️ **画在 canvas 上的坏串 `innerText` 扫不到** ⇒ 自检给 `txt/text/textScreen` 打桩扫传入的 str
  （三者 str 下标不同：`txt`→2、`text`→1、`textScreen`→2）；⚠️ `parseRich(undefined)`
  **不抛异常**（静默变成 "undefined" 照常排版）。
