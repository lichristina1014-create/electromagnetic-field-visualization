# 3.2 恒定电场的特点 · 装配源与回归自检

对应页面：`../../3.2-constant-field.htm`（**生成物，不要直接改**）

## 页面在讲什么

用户原话需求：

> 3.2 节能说清楚什么是局外力和局外场强的动态变化过程，有电源和没电源

依据 PPT（LCL-第3章-恒定电场）第 2 / 15 / 16 页。三页签：

| 页签 | state.mode | 讲什么 |
|---|---|---|
| ① 没电源 · 放电 | `nosrc` | 充了电的极板 + 导线 ⇒ 放电暂态：Q、E、I 全部按 e^(−t/τ) 衰减 ⇒ 静电场"一次性"，电流转瞬即逝 |
| ② 有电源 · 局外场 | `source` | 局外场强 E_e（橙，只在电源内部）把正电荷从 − 极搬回 + 极 ⇒ 动态建立后 Q、E、I 恒定 |
| ③ 环量 · 保守场 | `loop` | 路径 A（不经电源的小环）：∮E·dl = 0；路径 B（沿导线穿过电源）：∮E·dl = 0 且 ∫E_e·dl = ℰ |

## 物理模型（本页的地基）

- **回路**：xy 平面的矩形环（0.72 × 0.50 m），电源区在左边中段（`SEG` 分段参数化，弧长 s∈[0, 2.44)）
- **E 场**：两极板 = 一对**软化库仑点电荷** ±Q（软化半径 `PL_EPS=0.06`）⇒ E = −∇φ **严格保守**；
  `kQbase` 按「板间电位差 ≡ ℰ」标定 ⇒ ∫_电源段 E·dl = −ℰ 严格成立
- **E_e**：只在电源段，`EeVal = ℰ/(2·SRC_H)`（局外场电动势的定义 ⇒ ∫E_e·dl = ℰ 解析成立）
- **① 放电**：Q=Q₀e^(−t/τ)、I=(Q₀/τ)e^(−t/τ)；**② 建立**：Q=Q∞(1−e^(−t/τ))、I=I∞(1−e^(−t/τ))；
  场强随极板电荷走（`kQnow ∝ Qnow`）⇒ 箭头长度、载流子速度全自动跟着衰减/建立
- **③ 环路积分是"真算"的**：沿路径 720 段中点规则数值积分（路径 B 的电源段另加密 600 段，
  那里近极板 |E| 尖锐），残差 ~10⁻³ V 如实显示，不是贴上去的 0
- 单位制：ℰ 用 V、R 用 kΩ ⇒ I∞=ℰ/R 用 mA；Q 用 µC（C=0.5 µF）；τ 用 s（示意值）

## 踩坑记录（本页新添）

1. **源区标签大战**：电源盒 + 两极板 + +/− 符号 + E/E_e 两列箭头全挤在 ~60px 的一团里，
   斜视角下任何"世界方向"的标签锚点都会撞上邻居（vis32 实测连撞三轮 36%/68%/82%/92%）。
   最终方案：**全部改屏幕空间固定偏移** —— E_e/E 标签沿「源区中心→箭头列」的屏幕方向
   水平外移；「电源」沉到盒左下；极板标签离板 100px。
2. **极板电荷符号个数要封顶**（≤4）：符号是 ~8px 宽的字形，板长只有 0.11 m（~30px），
   n=6 时间距 5px ⇒ 相邻符号重叠 37%。
3. **chk 的"收敛到稳态"容差别写死 1e-4**：t=4τ 时 1−e⁻⁴ = 98.2% —— 按 2% 容差判。
4. 拖 t/s 滑块必须 `state.anim=null`（4.2 同款教训，写进 mkRange 的 set 里）。
