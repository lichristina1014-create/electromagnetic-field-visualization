## 物理模型
- 平行板电容充电（E(t)=E₀sin ωt）：Q=ε₀ES、I_c=dQ/dt、I_d=ε₀S·dE/dt ≡ I_c（**逐时刻严格相等**）
- **同一安培环 L_1**：S_1 平盘（导线穿过）/ S_2 鼓膜（穿过极板间）⇒ 同一个 B，安培定律自洽
- L_2 套在间隙：`r<R` 只包围 `(r/R)²·I_d`，`r≥R` 才包围全部电流，与 L_1 的外场相同
  （把 r 拖过 R=0.16 看读数由 0.19 pT 跳到 0.32 pT；这是 `chk52` ② 的新增断言）
- 数值真实（nA / pT 级）—— "位移电流极微弱但严格存在"本身是教学点

## 视觉口径（对齐教材示意图）
- 两块**有厚度**的米黄圆盘、盘面 9 个正负电荷网格；中央 5 根品红 E 箭头随 E(t) 变长、翻向
- 蓝色 B 场环：外大环套整台电容器 + 穿过间隙的内环（教材图的两条场线）；`a/b/r` 标在内环上
- 紫色 `L_1/L_2` 安培环是**独立显示层**（默认关闭）；讲 S1/S2 时打开，L2 会以紫色虚线叠在蓝色 B 环上
- 相机 `az=-1.10 / el=0.95 / zoom=1.15`：x 轴基本水平、盘面可读；纯侧视会让圆盘缩成一条线
- 首屏只留教材图元素（`car/surf/amp=false`）；点 `S_1/S_2` 按钮会自动打开曲面层与安培环
- `S_1/S_2` 与 `J_d` 的文字用 `textScreen` 固定在画布左上（避开轴线、盘面标签与模式条）

## 踩坑
- 圆盘平面是 y-z，相机若取 `az≈-π/2`（x 轴最水平），盘面宽度只剩 `cos(az)` ⇒ 退化成细线；
  取 `az=-1.10` 是"轴线可读 + 盘面可辨"的折中
- 盘面电荷与 a/b/L_2 在极端相机角会互撞：只保留必要标签，`b` 的屏幕偏移要大于 `a`
- 旧的"L_1 与 L_2 上 B 完全一样"只对 `r≥R` 成立；`r<R` 会得出错误结论（chk52 ② 已锁）
