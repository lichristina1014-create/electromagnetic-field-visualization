## 本轮抓到的坑（都已修，判据都留在了脚本里）

1. **`kchip` 的 key 过了 `richHTML`、value 没过** ★
   ⇒ ③ 的读数里 `'|@{E}| ∝ 1/r³'`（带标记的**值**）在画面上**字面**显示 `@{E}`。
   修法：`'<b>'+richHTML(v)+'</b>'`。**凡进 DOM 的串，键和值都要过 `richHTML`。**
   （2.2 只处理 key 是因为它的 value 全是纯数字 —— 照抄就会漏。）

2. **`infoCard` 只认 `['§','文本']`，而调用处全写的是单元素 `['§ 文本']`** ★★
   ⇒ 单元素那种被当成"普通行"，右列去取 `r[1]` 得 `undefined`，**画面上出现 4 处字面 "undefined"**
   （① 卡片两行 `轴线上 r = …`、②③ 卡片两行 `平均/固有偶极矩`）。
   修法：判据改成看**写法**（`r[0]==='§'` 或"单元素且首字符是 `§`"），并统一剥掉 `§` 标记。
   ⚠️⚠️ **它是 canvas 上画的 ⇒ DOM 扫查（`innerText`）根本看不到**。
   而且 **`parseRich(undefined)` 不抛异常**（静默 `String()` 成 `"undefined"` 再排版）
   ⇒ 控制台干净、断言全过、画面上却有一行 `undefined`。
   **唯一可靠的抓法是给 `txt`/`text`/`textScreen` 插桩**（→ `chk4_canvas.js`）。

3. **场线发射角用点偶极子公式反解 ⇒ 最外两条线冲出画布** ★★
   `r_max = d/(2 sin²α)` 只在点偶极子的等值线 `r = C·sin²θ` 上成立，
   而发射点在 **+q 附近（离原点只有 d/2）**，不在那条曲线上。
   实测 d=0.22 时公式给的 α=0.36 对应真实 `r_max = 1.72 m`，目标是 0.90 m。
   修法：**二分法实测反解** `alphaForRmax(target,d)`（`r_max(α)` 单调递减，lo 0.05 / hi 2.30 饱和点）。

4. **"曲线关于赤道面对称"的判据连错三次**（都写进了 `chk2_phys.js` 的注释）：
   · 逐序号比 `pts[i]↔pts[n−1−i]` ⇒ 偏差恰好 `d/2`（首点是发射点、末点被**吸附到 −q 本身**）；
   · 镜像点到原折线的**最短距离**（全曲线）⇒ 偏差恰好 `ε = 0.16d`（**端点空隙**支配）；
   · 按**弧长**配对 `s*` 与 `S−s` ⇒ 又是 `ε`（弧长配对默认两端互为镜像）。
   真相：**`ψ(x,−z) ≡ ψ(x,z)` 严格成立（解析残差 0.00e+0）** ⇒ 对称性**是构造性的**。
   ⇒ 拆成两条断言：① 解析判据必须**恰为 0**；② 折线几何上复现它（**只取中段** `θ∈[0.35,π−0.35]`，
   实测 2.7e-3 m 且**与窗口宽度无关**、与步长无关 = RK4 偏离等值线的漂移量级）。

5. **"两边并排的文字"会讲反** ★
   `mediaNote(0)` 写"左边是哑铃、右边是圆瓣"，但两块介质在世界坐标是 `x = ∓SLAB_CX`（极性在 −x），
   默认相机 `az=0.62` 下投影到屏幕**左右对调**（实测 水→屏幕 x=560.2、PE→屏幕 x=437.8）。
   修法：**一律用材料名（水 / PE）**，不用左/右。同一坑还在讲解卡正文里踩了一次。

6. **② 的面板写"按 ▶ 播放全过程"，但 ▶ 只长在 ③ 上** ⇒ **死文案**。
   修法：`mediaNote(E0, mode)` 加页签参数（③ 播放途中 `g=0` 也会走到这一支，那里才真有 ▶）。
   同时发现 ② 里**并排放了两段同义文字**（"还没极化/差别在微观"说两遍）⇒ 删掉重复那段。

7. **① 的四层显示开关可以全关 ⇒ `prims=0` ⇒ 整块空白画布**（而 ②③ 有常画的介质盒，关不空）。
   修法：`renderSubSec` 的 `onPick` 里守一道"至少保留一层"，并**把骨架里一直没接线的
   `#toast` 补成 `toastMsg()`**（它只有 CSS 和元素、从来没有 JS helper，是个死元素）。

8. 顺手清掉的：`STAGE_NAMES`（写死后没用上的死常量）、两处 `.replace('@ {p}','@{p}')` 补丁式写法。
